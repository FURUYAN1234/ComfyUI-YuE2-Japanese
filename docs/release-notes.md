# v1.2.1 — More lyric presets / 歌詞行数プリセットを追加

Choose 4, 8, 12, 16, 24 or 32 lyric lines, or enter a custom count from 1 to 64. / 歌詞行数は4・8・12・16・24・32行から選べ、自由指定1〜64行も使えます。

Manual-input behavior and song-duration controls remain unchanged. / 手動入力の動作と曲の秒数設定は維持します。

A shared mapping defines both choices and requested counts, with tests for every preset and invalid selections. / 選択肢と実際の指定行数を共通の定義で管理し、全プリセットと不正な選択を検査します。
