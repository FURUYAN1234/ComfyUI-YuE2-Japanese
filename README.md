# YuE2 日本語おまかせ作曲（このPC用）

ComfyUI の `03_音声/17_音楽_YuE2/YuE2_日本語おまかせ_LMStudio_GPU` を開き、①に日本語で雰囲気を書いて「実行する」を押します。例: 「雨の日にコンビニ行く感じ。ちょっと切ないけど明るい、女の子の声で。歌詞もおまかせ。」

既存の Qwen3.5 9B を LM Studio で GPU に読み込み、曲名・日本語歌詞・英語の曲調説明を生成します。LLMをアンロードした後、独立WSL環境の YuE2-3B が同じ RTX 5080 を使って歌と伴奏を生成します。③で再生、④に歌詞と保存先を表示します。クラウドの作曲APIは使いません。

## 保存先と設定
- ワークフロー: `/home/furu/ComfyUI/user/default/workflows/03_音声/17_音楽_YuE2`
- 曲: `/home/furu/ComfyUI/output/audio/YuE2/日時_ID/`。`audio.flac`、`song_plan.json`（元の指示・歌詞・曲調）、`score.abc`、実行設定・生成記録を保存します。
- 独立環境・作業記録: `/home/furu/Codex/work/yue2`。ComfyUI側には `custom_nodes/comfyui-yue2-local` だけを追加し、YuE2依存ライブラリは専用 `.venv` に隔離しています。
- 短い試作: 歌詞4行。通常: 16行。秒数はYuE2の生成結果によって変わり、固定秒数ではありません。通常16行の実生成は未検証です。
- seed: ①は作詞、②は曲生成。既定では実行後にランダム化します。同じ候補を再現するときは両方を固定します。
- 同時に重い画像・動画・他のLLMをGPUへ読み込むとメモリを圧迫します。作曲中は同じGPUの生成を順番に実行してください。

## 起動と停止
既存の方法で ComfyUI を起動してください。LM Studio のローカルサーバーが停止していれば①がWSL側インターフェースの1234番ポートで起動を試みます。LM Studio が終了していたりポートが使用中の場合は、そのエラーが表示されます。

②の実行中に中止ボタンを押すと、このワークフローが開始したYuE2子プロセスだけを終了します。①のモデル読み込みや作詞HTTP通信中は、その処理が戻るまで中止が反映されない場合があります（通信・読み込み上限180秒）。エラー時は `/home/furu/Codex/work/yue2/jobs` の該当日時ログと、出力フォルダーの隣の `.state.json` を確認します。失敗出力を完成曲として返しません。

## 検証
RTX 5080 16GB、WSL Ubuntu、Python 3.12、PyTorch 2.10.0+cu128、sm_120 対応を現物で確認。独立環境で日本語歌詞4行を英語曲調と日本語の曖昧な曲調の双方で実生成しました。46.7秒・73.3秒の音声、生成の途中打切りなし。日本語側の4行はCPUのWhisperで認識されました。ASRには幻覚や省略があるため、音楽的な品質の試聴の代用にはしていません。生成時間・ピークメモリは ledger.json と各実行stateに残しています。

入力形式、余分な歌詞行の拒否、接続型とシード保存の回帰検証は `python3 /home/furu/Codex/work/yue2/test_contract.py` で実行できます。実ブラウザーの再読込・実ボタン操作・ComfyUI履歴での検証は台帳参照。
